# Poster Example: African Tech Summit Announcement

## Brief Analysis

**Project** : Tech Summit 2024 Poster
**Objective** : Increase event awareness and attendance
**Audience** : Tech entrepreneurs, developers, innovators in Africa
**Format** : A3 (297x420mm)
**Viewing Distance** : 1-3 meters (indoor poster)
**Timeline** : 1 month to event

---

## Creative Strategy

### Strategic Pillars

**Problem** : Limited visibility for African tech talent on global stage

**Opportunity** : Connect African innovators with international platforms

**Proof** : Previous summits attracted 2,000+ participants from 15 African countries

**Proposition** : Premier networking event for African tech community

### Creative Angle Selected

**OPPORTUNITY** — Focus on possibilities and access

Visual language: Forward-looking, open, aspirational, inclusive

---

## Creative Direction

### Primary Message

"TECH SUMMIT 2024"

**Subheading** : "Where African Innovation Meets Global Opportunity"

### Hook

Bold, striking image: African city skyline at sunset with tech overlays (circuit patterns, data visualization elements)

### Color Palette

- Brand Blue (#013C87) — Headlines, structural elements
- Light Teal (#2BA696) — Accent, highlighting key info
- White (#FFFFFF) — Clean backgrounds
- Brand Green (#1D7742) — CTA elements

---

## Typography

| Element | Font | Size (A3 Print) | Weight | Color |
|---------|------|---|--------|-------|
| Main Headline | Inter | 96pt | 800 | #013C87 |
| Subheading | Inter | 40pt | 600 | #2BA696 |
| Details | Inter | 28pt | 400 | #0A2555 |
| CTA | Inter | 40pt | 700 | #FFFFFF |
| Metadata | Inter | 14pt | 400 | #666666 |

### Readability at Viewing Distance

**1 meter**: Headline easily readable (96pt = ~35mm, legible from 1m)
**3 meters**: Still legible with effort, main message clear
**5 meters**: "TECH SUMMIT 2024" dominates, clear focus

---

## Imagery

**Concept** : Futuristic visualization of African technological advancement

**Main Visual** : Cityscape (Nairobi, Lagos, or Accra) with:
- Modern skyscrapers
- Digital/tech overlay (subtle circuit patterns, data points)
- Warm sunset lighting
- Clean, contemporary aesthetic

**Execution** :

- 40% of poster height
- Full-width bleed
- Tech elements (10-15% opacity, don't overpower)
- Color grading emphasizes warmth and optimism

---

## Call to Action

**Primary CTA** : "Get Your Tickets Now"

**URL** : www.techsummit2024.com

**Button Treatment** :

- Background: Brand Green (#1D7742)
- Text: White, 40pt, bold
- Size: Large (100% poster width effective area)
- Position: Bottom, prominent

---

## Quality Control Verification

✓ Readable at 1-3 meter distance? Headline legible from 3m — YES
✓ Minimal text, maximum impact? Only essential info — YES
✓ Single focal point? Image + headline — YES
✓ Brand identity clear? Colors, typography consistent — YES
✓ Event details clear? Date, location, CTA prominent — YES
✓ Professional appearance? High-quality image, clean layout — YES
✓ Feels premium and aspirational? Design reflects opportunity angle — YES
✓ CTA obvious? Large green button, clear URL — YES

## Printing Specifications

- **Paper** : 200gsm matte poster stock (preferred for professional look)
- **Finish** : Matte (reduces glare)
- **Quantity** : 500 copies
- **Distribution** : Co-working spaces, universities, tech communities, partner locations
- **Bleed** : 5mm on all sides (for accurate trimming)
- **Preflight** : All fonts embedded, color verified

**Timeline** :
