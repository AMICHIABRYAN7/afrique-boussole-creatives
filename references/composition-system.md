# Afrique Boussole — Composition System

## Overview

Le Composition System fournit des structures visuelles éprouvées pour organiser les éléments de manière cohérente, équilibrée et hiérarchisée.

Chaque composition doit servir le contenu et la stratégie, pas le contraire.

---

## 1. FUNDAMENTAL PRINCIPLES

### Principle 1: Visual Hierarchy

Not all elements are equal. Clear dominance is essential.

**Practice** :

- Make the most important element 2-3x larger than supporting elements
- Use color and contrast to emphasize primary message
- Use placement to guide eye flow
- Reserve white space around primary elements

**Wrong** :

- All elements roughly same size
- Multiple competing focal points
- Unclear what to look at first

---

### Principle 2: Balance

Visual weight should feel stable, not chaotic.

**Symmetrical Balance** :

- Elements mirror each other (formal, professional)
- Good for corporate, institutional messaging
- Can feel static if not executed carefully

**Asymmetrical Balance** :

- Elements arranged off-center but visually balanced
- More dynamic and modern
- Requires careful placement to avoid feeling off-kilter

**Radial Balance** :

- Elements radiating from central point
- Circular or spherical arrangement
- Creates focus on center

**Tension and Release** :

- Cluster elements on one side, balance with white space
- Creates visual interest without chaos
- Common in modern design

---

### Principle 3: Alignment

All elements should align to a grid or clear system. No random placement.

**Benefits** :

- Professional appearance
- Better readability
- Easier to scan
- Cohesive composition
- Mobile-friendly

**Practice** :

- Use invisible grid (8px, 4px, or typography line height)
- Align text to left, center, or right consistently
- Align images and blocks to grid points
- Avoid arbitrary placement

---

### Principle 4: Contrast

Difference creates interest. Similarity creates cohesion.

**Contrast Types** :

- **Color** : Brand colors against neutral backgrounds
- **Size** : Large primary against small supporting
- **Weight** : Bold headlines against regular text
- **Shape** : Angular elements against organic shapes
- **Density** : Cluster vs. white space
- **Direction** : Horizontal text vs. vertical imagery

**Caution** :

- Too much contrast = chaos
- Too little contrast = boring
- Aim for "clear contrast with visual harmony"

---

### Principle 5: Repetition

Repeated elements create unity and recognition.

**Practice** :

- Use same colors consistently
- Repeat typographic styles
- Use same iconography style
- Apply same design treatments
- Maintain grid structure

**Effect** :

- Strengthens brand recognition
- Creates visual cohesion
- Builds anticipation (pattern recognition)
- Calms the eye

---

### Principle 6: White Space (Negative Space)

Empty space is not wasted space. It's essential.

**Functions** :

- Allows elements to breathe
- Creates focus by isolating elements
- Reduces cognitive load
- Improves readability
- Communicates quality and premium positioning

**Practice** :

- Reserve 15-25% of canvas as active white space
- Cluster elements, then leave breathing room
- Use margins and padding consistently
- Don't feel obligated to fill every inch

## 2. COMPOSITION SYSTEMS

### System 1: RULE OF THIRDS

**Structure** :

```
┌───────────────┬───────────────┬───────────────┐
│               │               │               │
│       A       │       B       │       C       │
│               │               │               │
├───────────────┼───────────────┼───────────────┤
│               │               │               │
│       D       │       E       │       F       │
│               │               │               │
├───────────────┼───────────────┼───────────────┤
│               │               │               │
│       G       │       H       │       I       │
│               │               │               │
└───────────────┴───────────────┴───────────────┘
```

**Focal Points** : Intersection points (B+D, B+F, H+D, H+F)

**How to Use** :

- Place primary element at intersection point (not dead center)
- Align secondary elements to grid lines
- Balance weight across grid
- Use intersections for focal point placement

**Best For** :

- Photography-based designs (place subject on line)
- Balanced, professional layouts
- Multi-element compositions
- Creating dynamic but stable layouts

**Example** :

- Headline at top-right intersection
- Image spanning middle-left area
- CTA button at bottom-right intersection

---

### System 2: CENTERED COMPOSITION

**Structure** :

```
         ┌─────────────────────┐
         │                     │
         │   PRIMARY ELEMENT   │
         │     (centered)      │
         │                     │
         ├─────────────────────┤
         │                     │
         │  SUPPORTING TEXT    │
         │                     │
         ├─────────────────────┤
         │   SECONDARY VISUAL  │
         │     (centered)      │
         │                     │
         ├─────────────────────┤
         │   CTA / LOGO        │
         │     (centered)      │
         └─────────────────────┘
```

**When to Use** :

- Institutional, formal communication
- Strong headline requiring full attention
- Ceremonial or special announcement
- Web landing pages
- Promotional posters

**Advantages** :

- Formal and structured
- No ambiguity about focal point
- Professional appearance
- Works well with symmetrical content

**Risks** :

- Can feel static or traditional
- Less dynamic than asymmetrical
- Must have truly compelling primary element

---

### System 3: SPLIT LAYOUT

**Structure** :

```
┌──────────────────┬──────────────────┐
│                  │                  │
│  IMAGE / VISUAL  │  TEXT / MESSAGE  │
│                  │                  │
│                  │                  │
│                  │                  │
└──────────────────┴──────────────────┘
```

Or vertically:

```
┌──────────────────────────────┐
│   IMAGE / VISUAL             │
├──────────────────────────────┤
│   TEXT / MESSAGE / CTA       │
└──────────────────────────────┘
```

**When to Use** :

- Combining distinct content (image + message)
- Product showcase + description
- Before/after scenarios
- Two competing ideas
- Left-brain / right-brain messaging

**Balance** :

- Each side gets roughly 50% space
- Or 60/40 if one side is heavier
- Visual weight must feel balanced

---

### System 4: ASYMMETRIC / DYNAMIC COMPOSITION

**Structure** :

```
┌────────────┬─────────────────────────┐
│  PRIMARY   │                         │
│  ELEMENT   │  WHITE SPACE /          │
│  (65%)     │  SECONDARY ELEMENT      │
│            │  (35%)                  │
└────────────┴─────────────────────────┘
```

**When to Use** :

- Modern, energetic communications
- Breaking traditional layouts
- Creating visual interest
- Tech/startup/innovative positioning
- Social media (platform nature demands movement)

**Execution** :

- Place heavy element on one side
- Balance with white space and/or lighter secondary element
- Ensure overall weight distribution feels intentional
- Avoid feeling "oops, we ran out of space"

---

### System 5: Z-LAYOUT / F-LAYOUT

**Z-Layout (for Western left-to-right reading)** :

```
START ──────→ ┌──────────────────┐
              │  PRIMARY ELEMENT  │
              └──────────────────┘
                      ↓
           ↙──────────┴──────────↘
    SECONDARY              TERTIARY
   INFORMATION            INFORMATION
           ↘──────────┬──────────↙
                      ↓
           ┌──────────────────┐
           │   CTA / ACTION   │ ← END
           └──────────────────┘
```

**F-Layout (for content-heavy pages)** :

```
┌──────────────────────────────────┐
│ HEADLINE / KEY INFORMATION       │
├──────────────┬──────────────────┤
│              │                  │
│ PRIMARY AREA │ SECONDARY INFO   │
│ (70%)        │ (30%)            │
│              │                  │
├──────────────┼──────────────────┤
│ CTA / ACTION │ FOOTER / LINKS   │
└──────────────┴──────────────────┘
```

**When to Use** :

- Multi-section layouts
- Web pages and landing pages
- Posters with multiple information levels
- Content-rich communications

---

### System 6: DIAGONAL LAYOUT

**Structure** :

```
Primary Element positioned on diagonal line
to create dynamic flow

╱ MOVEMENT DIRECTION

Element placement follows diagonal from 
top-left to bottom-right (or vice versa)
```

**When to Use** :

- Action/movement themes
- "Going somewhere" messaging
- Dynamic, energetic communications
- Directional or journey narratives

**Caution** :

- Diagonal can feel chaotic if not controlled
- Use grid to anchor diagonal elements
- Maintain overall balance
- Don't abuse multiple diagonals

---

### System 7: EDITORIAL LAYOUT

**Structure** :

```
Classic magazine/editorial approach:

HEADLINE (full width, large)
───────────────────────────

IMAGE (spans columns) │ COLUMN A TEXT
                      │
                      │ Supporting info
                      │ in narrow column
```

**When to Use** :

- Magazine-style communications
- Storytelling formats
- Long-form journalism/articles
- Premium brand communications
- Case studies

## 3. FOCAL POINT TECHNIQUES

### Technique 1: Size Dominance

**Practice** : Make primary element 3x larger than secondary

**Example** :

- Headline: 72px
- Subheading: 24px
- Body: 16px

### Technique 2: Color Contrast

**Practice** : Place brand color on neutral background, or vice versa

**Example** :

- Brand Blue (#013C87) on White
- White text on Brand Blue background

### Technique 3: Placement

**Practice** : Position focal point at rule-of-thirds intersection or center

**Example** :

- Top-right intersection for headline
- Center for centered layout
- Top-left for left-to-right reading

### Technique 4: Isolation

**Practice** : Surround focal point with white space

**Example** :

- Headline with generous margins
- Image with breathing room

### Technique 5: Directional Cues

**Practice** : Use arrows, lines, or natural eye gaze to direct to focal point

**Example** :

- Compass pointing to headline
- Route line leading to CTA
- Person's gaze toward key element

### Technique 6: Lighting/Vignette

**Practice** : Use shadow or vignette to highlight focal area

**Example** :

- Gradient overlay focusing on headline area
- Lighter background, darker frame edges

## 4. TEXT HIERARCHY IN COMPOSITION

### Visual Weight of Text

Text weight hierarchy should mirror visual hierarchy:

```
┌─────────────────────────────────┐
│ HEADLINE (72px, Weight 700)     │ ← Dominant
│                                 │
├─────────────────────────────────┤
│ Subheading (28px, Weight 600)   │ ← Secondary
│                                 │
├─────────────────────────────────┤
│ Body text (16px, Weight 400)    │ ← Supporting
└─────────────────────────────────┘
```

### Text Placement Within Layout

- **Headline** : Top third or center (depending on layout)
- **Subheading** : Below headline or alongside image
- **Body** : Middle to lower areas
- **CTA** : Bottom or prominent placement (natural eye endpoint)
- **Logo/Metadata** : Lowest priority, periphery

### Text Alignment

- **Left align** : Most readable for body text, professional
- **Center align** : Formal, ceremonial, web landing pages
- **Right align** : Use sparingly, can feel off-balance
- **Justified** : Use with caution (can create poor word spacing)

**Rule** : Use one alignment consistently throughout layout (except intentional variation)

## 5. NEGATIVE SPACE MANAGEMENT

### Planning Negative Space

**Allocation** :

- Content: 75-85% of canvas
- Negative space: 15-25% of canvas

**Distribution** :

- Margins (top/bottom): 10-15%
- Margins (left/right): 8-12%
- Internal breathing room: 5-15%

### Creating Effective Negative Space

1. **Margins** : Equal padding around canvas edges
2. **Gutters** : Space between columns or sections
3. **Isolation** : White space around focal point
4. **Breathing Room** : Space between text lines, elements
5. **Visual Rest** : Areas with no content to rest the eye

### Negative Space Mistakes

- Filling every inch of canvas
- Uneven margins
- Cramped text with tight line spacing
- Elements touching each other
- No visual breathing room

## 6. RESPONSIVE ADAPTATION

Composition must adapt to format while maintaining hierarchy:

### From A4 (210x297mm) to 1:1 Social (1080x1080px)

**A4 (Portrait) Original** :

```
┌─────────────────────┐
│ HEADLINE            │
│ (full width top)    │
├──────────┬──────────┤
│ IMAGE    │ TEXT     │
│ (60%)    │ (40%)    │
├──────────┴──────────┤
│ CTA BUTTON          │
└─────────────────────┘
```

**1:1 Social Adaptation** :

```
┌─────────────────────┐
│ IMAGE               │
│ (background)        │
│                     │
│ HEADLINE            │
│ (overlaid, centered)│
│                     │
│ CTA STICKER         │
│ (bottom)            │
└─────────────────────┘
```

**Principle** : Recompose, don't just shrink. Hierarchy and readability must be maintained.

---

## 7. COMPOSITION CHECKLIST

Before finalizing layout:

- [ ] Primary focal point is obvious
- [ ] Hierarchy is clear (sizes, colors, placement)
- [ ] All elements align to grid or intentional system
- [ ] Balance feels stable (symmetrical or intentionally asymmetrical)
- [ ] White space is active and intentional
- [ ] Text is readable at intended viewing distance
- [ ] Eye path flows naturally (Z, F, or designed path)
- [ ] No competing focal points
- [ ] Brand elements present and correctly placed
- [ ] Layout works on primary platform/format
- [ ] Layout can adapt to other formats while maintaining integrity
- [ ] Nothing feels cramped or suffocating
- [ ] Nothing feels too sparse or unfinished
- [ ] Composition serves content (not vice versa)
