# Afrique Boussole — Creative Framework

## Overview

Le Creative Framework décompose chaque création en composants élémentaires, permettant à l'IA de construire le visuel de manière méthodique et cohérente.

Ce framework garantit que chaque élément a une fonction et contribue à l'objectif global.

---

## 1. THE PYRAMID MODEL

Chaque création Afrique Boussole doit construire une hiérarchie visuelle claire :

```
                    ┌──────────────────┐
                    │   LEVEL 1: HOOK  │
                    │  (Attention grab)│
                    └──────────────────┘
                           ▼
                    ┌──────────────────┐
                    │ LEVEL 2: MESSAGE │
                    │ (Primary message)│
                    └──────────────────┘
                           ▼
                    ┌──────────────────┐
                    │ LEVEL 3: VALUE   │
                    │ (Why it matters) │
                    └──────────────────┘
                           ▼
                    ┌──────────────────┐
                    │ LEVEL 4: PROOF   │
                    │ (Why trust us)   │
                    └──────────────────┘
                           ▼
                    ┌──────────────────┐
                    │ LEVEL 5: CTA     │
                    │ (What to do next)│
                    └──────────────────┘
```

### LEVEL 1: HOOK (Attention Layer)

**Purpose** : Stop the scroll. Create attention in first 0.5 seconds.

**Not always explicit text** — can be:

- Bold visual contrast
- Unexpected image
- Striking color combination
- Geometric composition
- Motion (in dynamic formats)

**Examples** :

- "African Entrepreneurs Survey 2024" (statistic as hook)
- Bold compass visual dominating the frame
- Contrasting photography
- Surprising juxtaposition
- Question that resonates

**Size in Hierarchy** : 35-45% of visual real estate should support the hook

---

### LEVEL 2: MESSAGE (Primary Communication)

**Purpose** : Communicate the core idea clearly.

**Usually** : Headline or primary visual element

**Must be** :

- Single, focused idea
- Readable in 2-3 seconds
- Aligned with creative angle
- Visually dominant
- Using Brand colors

**Examples** :

- "Navigate African Markets with Confidence"
- "Strategy for Growth"
- "Your Compass for Success"
- Headline + supporting image combination

**Size in Hierarchy** : 25-35% of visual real estate

---

### LEVEL 3: VALUE (Benefit Layer)

**Purpose** : Explain why they should care.

**Usually** : Subheading or supporting text

**Answers** :

- "What's in it for me?"
- "What problem does this solve?"
- "What opportunity does this unlock?"

**Examples** :

- "Expert guidance for market entry"
- "Access proven strategies for African growth"
- "Build your competitive advantage"
- "Join 500+ successful entrepreneurs"

**Size in Hierarchy** : 15-20% of visual real estate

---

### LEVEL 4: PROOF (Credibility Layer)

**Purpose** : Provide evidence and build trust.

**Can be** :

- Statistics / Data
- Testimonial
- Logo / Partnership
- Credentials
- Results / Impact
- Years of experience
- Media mentions
- Community size

**Examples** :

- "Trusted by 500+ African businesses"
- "15 years in African markets"
- "Featured in Forbes, TechCrunch, Wired"
- "94% client success rate"
- "Partnerships with AfDB, IFC, World Bank"

**Important** :

- Use only TRUE proof
- Never invent testimonials or statistics
- Use placeholders if data isn't available
- Keep proof factual and verifiable

**Size in Hierarchy** : 10-15% of visual real estate (or omitted if not essential)

---

### LEVEL 5: CTA (Action Layer)

**Purpose** : Direct them to the next step.

**Must be** :

- Clear and specific
- Visually prominent
- Easy to execute
- Aligned with objective

**Examples** :

- "Sign up for the webinar"
- "Download our market guide"
- "Contact us for a consultation"
- "Join our community"
- "Learn more at afrique-boussole.com"
- "Register now" or "Apply today"

**Visual Treatment** :

- Button with contrasting color (typically Brand Green #1D7742)
- White or contrasting text
- Sufficient padding
- Positioned in natural eye flow

**Size in Hierarchy** : 5-10% of visual real estate (but must be visually clear)

## 2. ESSENTIAL ELEMENTS CHECKLIST

Every creative must have:

- [ ] **HOOK** : Something that stops attention (visual or textual)
- [ ] **PRIMARY MESSAGE** : Single, clear headline
- [ ] **SECONDARY MESSAGE** or **VALUE** : Why it matters
- [ ] **VISUAL FOCAL POINT** : Where the eye should go first
- [ ] **BRAND ELEMENT** : Logo, colors, or brand marker
- [ ] **CTA** : Clear next action

### Optional Elements (Use if They Add Value)

- Supporting image or photography
- Secondary visual element (compass, map, etc.)
- Supporting proof or statistic
- Testimonial or case reference
- Data visualization
- Decorative element (pattern, graphic)

### Never Include

- Unnecessary elements
- Competing focal points
- Cluttered composition
- Conflicting messages
- Unclear CTAs
- Small or illegible text
- Generic or low-quality imagery

---

## 3. COMPONENT MAPPING

### Visual Focal Point

**Definition** : The element where the viewer's eye naturally goes first.

**Usually the HOOK** :

- Bold image
- Large headline
- Color contrast
- Geometric shape

**Must be** :

- Clear and immediate
- Supporting the primary message
- Using composition rules (rule of thirds, center, contrast)
- Taking 30-40% of visual space

**Position** :

- Top third (for social, to appear above fold)
- Center (for balanced composition)
- Left (for natural reading flow, especially Arabic/RTL)
- Based on format and platform

---

### Brand Element Placement

**Primary** : Logo in bottom right or top left

**Secondary** : Brand colors dominant in composition

**Tertiary** : Brand visual system elements (compass, map symbols)

**Size** :

- Logo: 15-25mm (print), 40-80px (digital)
- Logo must not compete with primary message
- Logo must be visible but not dominant (exception: brand-focused campaigns)

**Contrast** :

- Logo must be on contrasting background
- Use clear space around logo
- Never overlay logo on busy imagery

---

### Text Hierarchy Components

| Level | Font Size | Weight | Color | Function |
|-------|-----------|--------|-------|----------|
| Hook/Headline | 48-96px | 700 | Brand Blue | Primary message |
| Subheading | 24-40px | 600 | Brand Blue/Dark Navy | Supporting message |
| Body | 14-18px | 400 | Dark Navy | Explanation, proof |
| CTA Label | 14-16px | 600 | White | Action button |
| Caption | 10-12px | 400 | Dark Navy | Metadata, source |

## 4. FUNCTIONAL VARIATIONS

The pyramid model can be adapted based on content type:

### Text-Heavy (Educational, Complex Info)

```
HOOK: Striking visual or provocative statement
MESSAGE: Clear headline explaining concept
VALUE: 2-3 supporting points
PROOF: Research or credibility
CTA: Learn more / Download / Register
```

### Image-Heavy (Storytelling, Emotional)

```
HOOK: Powerful image dominating the frame
MESSAGE: Headline supporting the image
VALUE: Short, emotive copy
PROOF: Can be subtle (logo, partner)
CTA: Clear but minimal
```

### Data-Driven (Analytics, Intelligence)

```
HOOK: Surprising data point or visualization
MESSAGE: What the data means
VALUE: Actionable insight
PROOF: Data source, methodology
CTA: Access full report / Analysis
```

### Minimalist (Premium, Corporate)

```
HOOK: Bold typography or negative space
MESSAGE: Single line, powerful headline
VALUE: Optional (often omitted for simplicity)
PROOF: Subtle (color, symbol)
CTA: Simple call (visit website)
```

### Crowded (Event, Multiple Info Points)

```
HOOK: Date, location, or event name (prominent)
MESSAGE: Event focus or main draw
VALUE: Key details or benefits
PROOF: Speakers, partners, past attendance
CTA: Register now (with urgency)
```

## 5. FLOW AND PROGRESSION

The viewer's eye should flow naturally through the pyramid:

### Optimal Flow (Z-pattern for Western audiences)

```
1. Hook (top-left or large visual)
   ↓ (left to right)
2. Message (headline center/right)
   ↓ (diagonal down-right)
3. Value / Supporting (lower area)
   ↓ (horizontal left)
4. CTA (bottom-right)
```

### Optimal Flow (Circular for Multi-Format)

```
1. Visual focal point (draws attention)
2. Headline follows natural eye path
3. Supporting text continues flow
4. CTA positioned at natural conclusion
```

### Wrong Flow (Chaos)

- Competing focal points
- Text scattered without hierarchy
- CTA not positioned as endpoint
- Logo competing with message
- No clear entry or exit point

## 6. COMPOSITION INTEGRATION

The Pyramid Model works within composition systems:

### Within Rule of Thirds

```
┌───────────────┬───────────────┬───────────────┐
│ Hook/Message  │               │ Logo/Brand    │
│ (L1+L2)       │               │               │
├───────────────┼───────────────┼───────────────┤
│               │ Visual        │               │
│               │ Focal Point   │ Value         │
│ Supporting    │ (main image)  │ (L3)          │
│               │               │               │
├───────────────┼───────────────┼───────────────┤
│ CTA / Proof   │               │ CTA           │
│ (L4+L5)       │               │ (L5)          │
└───────────────┴───────────────┴───────────────┘
```

### Within Center Composition

```
         ┌─────────────────────┐
         │    HOOK             │
         │    MESSAGE (L1+L2)  │
         │                     │
         │  ┌───────────────┐  │
         │  │ Visual        │  │
         │  │ Focal Point   │  │
         │  │               │  │
         │  └───────────────┘  │
         │                     │
         │ VALUE (L3)          │
         │ PROOF (L4)          │
         │ CTA (L5)            │
         │                     │
         │ LOGO                │
         └─────────────────────┘
```

## 7. RESPONSIVE ADAPTATION

The Pyramid Model adapts to different formats:

### 1:1 Social (Square)

- Hook/Message: Large, top half
- Image: Center or full background
- CTA: Bottom, compact
- Logo: Bottom corner, small

### 4:5 Social (Portrait)

- Hook: Top half (more space for headline)
- Image: Center
- Message/CTA: Lower portion
- Logo: Bottom

### 9:16 Social (Story)

- Hook: Top 1/3
- Message: Top 1/2
- Image: Center area
- CTA: Bottom 1/3 (sticker-like)

### 16:9 Web (Landscape)

- Hook/Image: Left or full background
- Message: Centered or right side
- Value/CTA: Right or bottom-right
- Logo: Bottom right

### A4 Print (Portrait)

- Hook: Top
- Image: Upper-middle
- Message/Value: Middle
- CTA: Lower area
- Logo: Bottom

## 8. ELEMENT SIZING GUIDELINES

### Based on Overall Canvas

```
Total visual real estate = 100%

Hook/Message combination:  35-45%
Visual focal point:        30-40%
Supporting elements:       15-20%
CTA:                       5-10%
Logo/Branding:             5-10%
Negative space:            5-15% (must-have)
```

### Text Sizing Hierarchy

- Primary Message: 3-5% of canvas height
- Secondary Message: 2-3% of canvas height
- Body text: 1-1.5% of canvas height
- CTA label: 1.5-2% of canvas height

## 10. VALIDATION AGAINST FRAMEWORK

Before finalizing, check:

- [ ] All 5 levels are present (or intentionally omitted)
- [ ] HOOK is attention-grabbing and clear
- [ ] PRIMARY MESSAGE is single and dominant
- [ ] VALUE addresses the audience need
- [ ] PROOF is credible (or omitted if not available)
- [ ] CTA is clear and positioned as endpoint
- [ ] Visual focal point is obvious
- [ ] Brand element is present and correct
- [ ] Flow is natural and predictable
- [ ] Negative space allows breathing room
- [ ] Element sizing feels balanced
- [ ] No competing focal points
- [ ] Composition serves the content
- [ ] Feels authentically Afrique Boussole
