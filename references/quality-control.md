# Afrique Boussole — Quality Control Framework

## Overview

Every creative must pass rigorous quality control before publication.

This framework ensures consistency, professionalism, and brand integrity across all Afrique Boussole communications.

---

## 1. QA CHECKLIST: BRAND COMPLIANCE

### Brand Elements

- [ ] **Logo present** and correctly placed (bottom right, top left, or center)
- [ ] **Logo size** respects minimum and maximum sizing rules
- [ ] **Logo clear space** maintained (1/4 logo height minimum)
- [ ] **Logo has sufficient contrast** with background
- [ ] **Logo not distorted** (aspect ratio maintained)
- [ ] **Logo not recolored** (uses brand colors or white/monochrome only)
- [ ] **Logo not rotated** (0° or 90° only, exception: max 15° for dynamic)

### Colors

- [ ] **Brand Blue #013C87** used where specified (not substituted with similar blue)
- [ ] **Brand Green #1D7742** used where specified (not substituted with similar green)
- [ ] **Neutrals correct** (White #FFFFFF, Ivory #F7F4EC as specified)
- [ ] **Total colors ≤ 5** in design
- [ ] **Color contrast WCAG AA minimum** (4.5:1 for text, 3:1 for large text)
- [ ] **No excessive color usage** (not rainbow, not chaotic)
- [ ] **Gradients** authorized (Blue-to-Green prohibited unless specified)

### Typography

- [ ] **Font stack correct** (Inter primary, IBM Plex Mono optional)
- [ ] **Font weights ≤ 2** per design (typically 400 + 700)
- [ ] **Headline size large enough** (minimum 48px for web, 36pt for print)
- [ ] **Body text readable** (minimum 14px digital, 10pt print)
- [ ] **Line height ≥ 1.5** for body text (preferably 1.6-1.8)
- [ ] **Letter spacing** appropriate (not cramped, not stretched)
- [ ] **Text alignment consistent** (one primary alignment throughout)
- [ ] **No all-caps body text** (except very short labels)

### Hierarchy

- [ ] **Focal point obvious** (clear where to look first)
- [ ] **Primary message dominates** (size, color, placement)
- [ ] **Secondary elements clearly secondary** (smaller, lower visual weight)
- [ ] **Supporting elements don't compete** with primary
- [ ] **CTA clear and positioned** as endpoint of eye flow
- [ ] **Hierarchy works at thumbnail size** (mobile 200px width test)

---

## 2. QA CHECKLIST: COMPOSITION AND LAYOUT

### Structure and Balance

- [ ] **Composition system intentional** (rule of thirds, centered, split, asymmetric, etc.)
- [ ] **Elements align to grid or system** (no random placement)
- [ ] **Balance appropriate** (symmetrical or intentionally asymmetrical)
- [ ] **No chaotic clustering** (related elements grouped, unrelated separated)
- [ ] **Negative space active** (15-25% of canvas intentionally empty)
- [ ] **Margins consistent** (top, bottom, left, right balanced)

### Readability and Scannability

- [ ] **Message readable in ≤ 2 seconds** (two-second test)
- [ ] **Headline legible at intended viewing distance**
- [ ] **Body text scannable** (short paragraphs, bullets if applicable)
- [ ] **CTA unmistakable** (stands out, clear action)
- [ ] **No text overlaid on busy imagery** (or background darkened/blurred)
- [ ] **Sufficient text/image contrast** (readable against background)
- [ ] **Not cramped or suffocating** (elements have breathing room)

### Visual Hierarchy and Focal Point

- [ ] **Entry point clear** (eye knows where to start)
- [ ] **Flow logical** (Z-pattern, F-pattern, or intentional path)
- [ ] **Exit point clear** (CTA is natural conclusion)
- [ ] **No competing focal points** (only one primary attention grab)
- [ ] **Supporting elements support** (don't distract)
- [ ] **Size hierarchy obvious** (primary 2-3x larger than secondary)
- [ ] **Color hierarchy clear** (different colors for different importance levels)

---

## 3. QA CHECKLIST: IMAGE QUALITY

### Image Technical Specs

- [ ] **Resolution appropriate** (minimum 1080px for digital, 300dpi for print)
- [ ] **Focus sharp** (no blur on primary subject, unless artistic intention)
- [ ] **Exposure correct** (not underexposed or overexposed)
- [ ] **Color grading professional** (natural or intentionally stylized, not artificial)
- [ ] **No visible artifacts** (compression, pixelation, distortion)
- [ ] **White balance consistent** (if multiple images in design)
- [ ] **Aspect ratio correct** for intended format

### Image Content and Strategy

- [ ] **Image supports message** (not redundant or contradictory)
- [ ] **Photography authentic** (not obviously clichéd stock photo)
- [ ] **Subject matter on-brand** (matches Afrique Boussole narrative)
- [ ] **Diversity appropriate** (representation authentic, not token)
- [ ] **Lighting professional** (not harsh, shadows, or artificial-looking)
- [ ] **Composition intentional** (not random or poorly framed)
- [ ] **Image readable with text overlay** (if text is overlaid)

---

## 4. QA CHECKLIST: TYPOGRAPHY DETAIL

### Text Rendering

- [ ] **No kerning issues** (letters not too close or too far)
- [ ] **No orphans or widows** (single word on line at paragraph end/start)
- [ ] **Hyphenation appropriate** (not excessive, words broken logically)
- [ ] **No text clipping** (all text fully visible, not cut off)
- [ ] **No overlapping text** (elements clear and separated)
- [ ] **Ligatures rendered correctly** (fi, fl, etc. if using)
- [ ] **Special characters correct** (accents, apostrophes, quotation marks)

### Readability and Accessibility

- [ ] **Font size minimum met** (14px digital, 10pt print)
- [ ] **Line length 45-75 characters** (ideal for readability)
- [ ] **Line height minimum 1.5** (preferably 1.6-1.8 for body)
- [ ] **Sufficient color contrast** (minimum WCAG AA 4.5:1 for text)
- [ ] **Not italicized for long passages** (only short emphasis)
- [ ] **Not using thin/light fonts** for body text (reduced legibility)
- [ ] **Sans-serif consistent** (same font family throughout)

### Multilingual Considerations

- [ ] **French spacing correct** (space before: !, ?, :, ;)
- [ ] **Accented characters supported** (é, è, ê, ë, à, ù, ç, etc.)
- [ ] **Line breaking appropriate** (French/English text fits without awkward breaks)
- [ ] **If RTL language** (Arabic, Hebrew), alignment reversed
- [ ] **Character encoding preserved** in all file formats

---

## 5. QA CHECKLIST: CTA AND INTERACTION

### CTA Visibility and Clarity

- [ ] **CTA visually prominent** (stands out from background)
- [ ] **CTA copy clear** (specific action, not vague)
- [ ] **CTA copy precise** ("Sign up for webinar" not "Learn more")
- [ ] **CTA action achievable** (link works, form accessible)
- [ ] **CTA button large enough** (minimum 44x44px for touchable elements)
- [ ] **CTA button color contrasts** (readable text on button background)
- [ ] **CTA positioned** as natural eye endpoint (bottom, right, or next to secondary element)

### CTA Design

- [ ] **Button has padding** (internal space for text/icon)
- [ ] **Button styling consistent** (matches brand system)
- [ ] **Link underlined or otherwise distinguished** from regular text
- [ ] **Hover state visible** (if interactive: color change, shadow, etc.)
- [ ] **Focus state clear** (for keyboard navigation accessibility)
- [ ] **CTA not competing** with primary headline or focal point

---

## 6. QA CHECKLIST: PLATFORM-SPECIFIC

### Social Media (1:1, 4:5, 9:16)

- [ ] **Dimensions correct** for platform
- [ ] **Safe zones respected** (avoid edges, platform UI areas)
- [ ] **Text readable at small size** (thumbnail test at 200px)
- [ ] **Image readable without sound** (if video, captions present)
- [ ] **CTA accessible** on platform (link, sticker, or caption link works)
- [ ] **Aspect ratio not distorted** (image not stretched)

### Web / Digital Display

- [ ] **File size optimized** (JPEG compressed, <2MB for web)
- [ ] **Responsive tested** (design works on mobile, tablet, desktop)
- [ ] **Links tested** (all URLs functional and correct)
- [ ] **Color accurate** in multiple browsers (Chrome, Firefox, Safari, Edge)

### Print

- [ ] **Color space CMYK** (not RGB, which looks different in print)
- [ ] **Resolution 300dpi minimum** (4 pixels per millimeter)
- [ ] **Bleed area specified** (1/2 inch on edges for cutting)
- [ ] **Safe margins honored** (no critical elements at edge)
- [ ] **Black text rich black** (400% density, not 100% K only)
- [ ] **Preflight check passed** (fonts embedded, images linked, no errors)

---

## 7. QA CHECKLIST: BRAND VOICE AND TONE

### Message Authenticity

- [ ] **Message feels Afrique Boussole** (not generic or templated)
- [ ] **Tone appropriate for audience** (professional for B2B, accessible for public)
- [ ] **Message honest and factual** (no exaggeration or false claims)
- [ ] **Claims backed by evidence** (if asserting something, proof provided or indicated)
- [ ] **No stereotyping** (diverse, authentic representation)
- [ ] **Language clear and professional** (no jargon, or jargon explained)
- [ ] **Call to action reasonable** (not manipulative or deceptive)

### Cultural Sensitivity

- [ ] **African representation authentic** (not stereotyped or clichéd)
- [ ] **Diversity present** (gender, age, ability, background)
- [ ] **Language appropriate** (French, English, or other language correctly used)
- [ ] **Cultural context respected** (if featuring African culture, accurate and respectful)
- [ ] **No offensive imagery or language** (tested against sensitivity guidelines)

---

## 8. QA CHECKLIST: PROFESSIONALISM

### Overall Polish

- [ ] **No typos or grammar errors** (spell-checked, grammar-checked)
- [ ] **No pixelation or distortion** (all elements crisp and clear)
- [ ] **No amateurish effects** (drop shadows, glows, distortions used sparingly)
- [ ] **No inconsistencies** (colors consistent, fonts consistent, sizing consistent)
- [ ] **No placeholder text** (all text finalized, no lorem ipsum)
- [ ] **No test elements visible** (watermarks, grid lines removed)
- [ ] **Final file clean** (no extra layers, artboards, or comments visible in export)

### Polish Details

- [ ] **Shadows subtle** (if used, serve purpose and look professional)
- [ ] **Opacity intentional** (not accidentally transparent elements)
- [ ] **Alignment pixel-perfect** (elements snap to grid)
- [ ] **Consistency across series** (if multiple creatives, cohesive aesthetic)
- [ ] **No "oops" elements** (stray marks, forgotten annotations)

---

## 9. CRITICAL FAIL INDICATORS

**If ANY of these are true, reject and revise:**

1. **Brand colors substituted** with non-brand colors (FAIL: Brand Blue replaced with Royal Blue)
2. **Logo distorted** or repositioned outside guidelines (FAIL: Logo stretched to 2x height)
3. **Text unreadable** at intended viewing size (FAIL: Body text 8px)
4. **Color contrast fails** WCAG AA (FAIL: Gray text on light gray background, 1.5:1 ratio)
5. **Multiple competing focal points** (FAIL: Can't tell what to look at first)
6. **Factually false claims** (FAIL: "99% of clients see results" if not true)
7. **Placeholder text still present** (FAIL: "Click here for more info" not replaced)
8. **Image obviously generic stock photo** (FAIL: Doesn't feel Afrique Boussole)
9. **CTA completely unclear** (FAIL: No action specified or button not clickable)
10. **Feels like generic template** (FAIL: Doesn't feel distinctive or authentic)

## 10. QA PROCESS

### Step 1: Self-Review (Creator)

Creator reviews against:

- Brand guidelines
- Creative strategy
- Format specifications
- Quality control checklist

Duration: 15-30 minutes

### Step 2: Peer Review (Another Designer/Team Member)

Peer checks:

- Brand compliance
- Hierarchy and readability
- Tone and voice
- Professionalism
- "Two second test" (does message read quickly?)

Duration: 10-15 minutes

### Step 3: Stakeholder Review (Client/Approval)

Stakeholder verifies:

- Strategic alignment with objective
- Message appropriateness
- CTA alignment with intent
- Factual accuracy (claims, statistics)

Duration: 10-20 minutes

### Step 4: Final Technical Check

Export and verify:

- Dimensions and resolution correct
- File size optimized
- Colors accurate in multiple formats
- Links functional (if applicable)
- Accessibility standards met (captions, alt text, etc.)

Duration: 5-10 minutes
