# Afrique Boussole — Campaign Formats

## Overview

A single creative concept must be adapted across multiple formats while maintaining message integrity, hierarchy, and brand identity.

This document defines standard formats and recomposition principles for each.

---

## 1. SOCIAL MEDIA FORMATS

### Format 1: 1:1 Square (Instagram Feed, LinkedIn, Facebook)

**Dimensions** :
- Minimum: 1080x1080px
- Aspect ratio: 1:1 (square)

**Design Principles** :

- **Focal point** : Center or top-center (appears above feed without scrolling)
- **Safe zone** : Avoid critical elements in outer 10% margins (subject to platform overlays)
- **Text placement** : Bottom half preferred (less likely to be covered by UI)
- **CTA** : Bottom right or bottom center

**Composition Suggestion** :

```
┌─────────────────────┐
│                     │
│  FOCAL POINT /      │
│  IMAGE              │
│  (60-70% of space)  │
│                     │
├─────────────────────┤
│                     │
│  HEADLINE /         │
│  MESSAGE            │
│  (overlaid or clear │
│  background area)   │
│                     │
├─────────────────────┤
│ CTA / LOGO          │
└─────────────────────┘
```

**Readability** :

- Minimum text size: 28px (for readability at thumbnail size)
- Headline must be readable at 200px width (mobile thumbnail)
- High contrast between text and background

**Content Types** :

- Eye-catching image with overlay headline
- Bold graphic with minimal text
- Product/service showcase
- Quote or statistic with supporting image
- Video thumbnail (still frame)

---

### Format 2: 4:5 Portrait (Instagram Feed, Reels Cover)

**Dimensions** :
- Minimum: 1080x1350px
- Aspect ratio: 4:5

**Design Principles** :

- **Vertical emphasis** : Image should work in portrait orientation
- **Top focus** : Primary message near top (visible without scroll)
- **Text safety** : Keep text in central band, avoid very top/bottom edges
- **CTA** : Bottom area

**Composition Suggestion** :

```
┌─────────────────┐
│  HEADLINE       │ ← Top area (appears first)
│  / HOOK         │
├─────────────────┤
│                 │
│  FOCAL POINT /  │
│  IMAGE          │
│  (dominant)     │
│                 │
│                 │
├─────────────────┤
│  SUPPORTING     │
│  MESSAGE        │
│                 │
│  CTA BUTTON /   │
│  LINK           │
│                 │
└─────────────────┘
```

**Readability** :

- More vertical space allows larger text
- Headline: 48-64px possible
- Body: 20-28px
- Readable at smartphone size (width ~400px)

**Content Types** :

- Event poster
- Product/service promotion
- Educational content (top-down flow)
- Story-style narrative
- Before-and-after

---

### Format 3: 9:16 Story/Vertical (Instagram Stories, TikTok, Shorts)

**Dimensions** :
- Minimum: 1080x1920px
- Aspect ratio: 9:16 (vertical, tall)

**Design Principles** :

- **Vertical entire frame** : Content must fill full vertical space
- **Safe zone** : Avoid top 100px and bottom 200px (reserved for platform UI)
- **Multiple layers** : Top, middle, bottom information
- **Text readability** : Must be readable at small size (viewers are mobile, scrolling fast)

**Composition Suggestion** :

```
┌─────────────────┐
│ STICKER / HOOK  │ ← Top (platform UI here)
├─────────────────┤
│                 │
│  HEADLINE /     │ ← Upper-middle
│  MESSAGE        │
│  (large, bold)  │
│                 │
├─────────────────┤
│                 │
│  IMAGE /        │ ← Center focal point
│  VISUAL         │
│  (full or       │ ← (important area)
│   background)   │
│                 │
├─────────────────┤
│  SUPPORTING     │ ← Lower area
│  TEXT           │
│                 │
│  CTA BUTTON /   │
│  STICKER        │ ← Bottom (platform UI here)
└─────────────────┘
```

**Text Sizing** :

- Headline: 56-72px
- Body: 24-32px
- Small: 16-20px
- Must be readable on 6-inch screen

**Animation Considerations** :

- If animated: ensure 3-second minimum per scene
- Consider text fade-in timing
- CTA sticker should persist for duration

**Content Types** :

- Behind-the-scenes
- Quick tips/education
- Announcements
- Event promotion
- Call-to-action driven

## 2. LANDSCAPE / HORIZONTAL FORMATS

### Format 4: 16:9 Landscape (Web Banners, YouTube, Presentations)

**Dimensions** :
- Minimum: 1920x1080px (full HD)
- Aspect ratio: 16:9

**Design Principles** :

- **Horizontal sweep** : Image fills left-to-right space
- **Left-centered text** : Natural reading flow
- **Right reserved** : For CTA or secondary element
- **Safe area** : Avoid edges (20px margin typical)

**Composition Suggestion** :

```
┌──────────────────────────────────────────┐
│ HEADLINE/      │                         │
│ MESSAGE        │  IMAGE / FOCAL POINT    │
│                │  (60% of width)         │
│ SUPPORTING     │                         │
│ TEXT           │                         │
│                │                         │
│ CTA BUTTON     │                         │
└──────────────────────────────────────────┘
```

**Variations** :

- Full-bleed image with overlay text (left side)
- Split: 50% image, 50% text
- Image background with foreground text

---

### Format 5: 1.91:1 Ultra-Wide (Facebook Cover, LinkedIn Banner)

**Dimensions** :
- Facebook: 1200x628px minimum (recommended 1920x1005px)
- LinkedIn: 1500x500px
- Aspect ratio: 1.91:1 approximately

**Design Principles** :

- **Very wide, short** : Emphasizes horizontal sweep
- **Text centered or left** : Limited vertical space
- **Single focal point** : Difficult to show multiple elements
- **Bold and simple** : Cannot have too much detail

## 3. PRINT FORMATS

### Format 6: A4 Portrait (Flyers, Letterhead, Documents)

**Dimensions** :
- Print: 210x297mm (8.3x11.7 inches)
- Digital: 2480x3508px at 300dpi
- Aspect ratio: 1:1.41

**Design Principles** :

- **Vertical flow** : Top to bottom reading
- **Margin safety** : 10mm margins on all sides
- **Typography hierarchy** : Clear progression
- **Multiple information levels** : Room for detail

**Composition Zones** :

```
┌─ 10mm margin ──────────────────┐
│                                │
│  HEADLINE / HERO VISUAL        │ ← Top third
│  (50% of height)               │
│                                │
├────────────────────────────────┤
│                                │
│  SUPPORTING MESSAGE            │ ← Middle third
│  (BODY TEXT / DETAILS)         │
│                                │
│                                │
├────────────────────────────────┤
│                                │
│  CTA / LOGO / FOOTER           │ ← Bottom third
│                                │
└─ 10mm margin ──────────────────┘
```

**Type Specifications** :

- Headline: 36-48pt
- Body: 10-11pt (readable in print)
- Line height: 1.5-1.8
- Resolution: 300dpi minimum

---

### Format 7: A3 Landscape (Posters, Large Displays)

**Dimensions** :
- A3: 297x420mm (11.7x16.5 inches)
- Digital: 3508x4961px at 300dpi
- Aspect ratio: 1:1.41 (portrait), but landscape shown here

**Design Principles** :

- **Large format** : Text and images can be bigger
- **Viewing distance** : Designed for viewing 1-3 meters away
- **Bold impact** : Simple, powerful design
- **Limited elements** : Few information layers

**Typical Poster Layout** :

- 40% image (full bleed or partial)
- 30% headline
- 20% supporting text
- 10% CTA / logo / footer

---

### Format 8: A2 (Billboard-Style Posters)

**Dimensions** :
- A2: 420x594mm (16.5x23.4 inches)
- Even larger viewing distance (2-5 meters)

**Design Principles** :

- **Maximum legibility** : Must be readable from far away
- **Very large type** : Headline 72pt+
- **Minimal text** : Only essential information
- **Bold imagery** : Eye-catching, simple
- **High contrast** : Must work in different lighting

## 4. FORMAT-SPECIFIC RECOMPOSITION

### Adapting A4 Flyer to 1:1 Social

**Original A4 Layout** :
```
Top 40% : Image + headline
Middle 30% : Body text
Bottom 30% : CTA + logo
```

**Adapted 1:1 Social** :
```
Top 50% : Image (cropped/resized)
Middle 30% : Headline (repositioned, resized)
Bottom 20% : CTA (compact version)
Remove: Detailed body text (not readable at thumbnail)
```

**Key Changes** :

- Crop image to square
- Enlarge headline for mobile readability
- Simplify body text to single line or remove
- Compact CTA to fit bottom
- Logo smaller or repositioned

---

### Adapting Poster to Stories (9:16)

**Original Poster (A3 Landscape)** :
```
Left 60% : Large image
Right 40% : Headline + supporting text + CTA
```

**Adapted Stories (9:16 Vertical)** :
```
Top 40% : Headline (enlarged)
Middle 50% : Image (recomposed, zoomed in)
Bottom 10% : CTA sticker / button
```

**Key Changes** :

- Reorient composition to vertical
- Enlarge headline for stories format
- Image might be zoomed in or focus on different part
- CTA becomes compact button/sticker
- Remove supporting text (not enough space)

## 5. RESPONSIVE DESIGN PRINCIPLES

### Information Hierarchy Preservation

**Must maintain across formats** :

- Same headline (text identical, sizing adjusted)
- Same primary message
- Same CTA (text identical, visual treatment adjusted)
- Same brand identity

**Can change across formats** :

- Image framing/cropping
- Secondary text (abbreviated or removed)
- Layout structure
- Supporting visual elements

### Text Adaptation

**Golden Rule** : Text remains readable at smallest intended viewing size

**Calculation** :

- 1:1 social viewed at ~300px width → minimum text 20px
- A4 print viewed at 30cm distance → minimum text 10pt
- 16:9 web banner viewed at full width → adjust to viewing distance

### Image Recomposition

**Never** : Simply shrink image to fit new format

**Always** :

1. Crop image appropriately for new aspect ratio
2. Reframe composition (focal point at appropriate position for format)
3. Test readability with overlaid text
4. Verify brand elements are visible

## 7. TECHNICAL SPECIFICATIONS

### File Formats

**Digital** : JPEG (RGB, 300dpi equivalent for web)

**Print** : JPEG or TIFF (CMYK, 300dpi minimum)

**Editing** : PSD, AI (retain layers for future edits)

### Color Spaces

**Digital** : RGB (sRGB)

**Print** : CMYK (prepare separate files)

**Conversion** : Use professional color management, not automatic browser conversion

### Font Handling

**Web** : Use web-safe fonts or embedded web fonts (WOFF2)

**Print** : Embed or outline fonts (avoid substitution)

### Exported Specs

**Social Media** : Optimized JPEG, file size <5MB

**Print** : High-res TIFF or PDF, CMYK, 300dpi, 400% black (rich black)

## 8. CHECKLIST: FORMAT ADAPTATION

Before adapting to new format:

- [ ] Hierarchy is preserved (same headline, message, CTA)
- [ ] Text is readable at intended viewing size
- [ ] Image is recomposed (not just shrunk)
- [ ] Brand elements are visible and appropriately sized
- [ ] Focal point is clear
- [ ] Negative space is intentional
- [ ] Color space is correct (RGB for digital, CMYK for print)
- [ ] Resolution is appropriate (300dpi for print, 72dpi+ for web)
- [ ] Safe zones respected (avoid edges, platform UI areas)
- [ ] Tested on intended display device/platform
- [ ] Tested with overlaid text (if applicable)
- [ ] Tested in different lighting conditions (print)
