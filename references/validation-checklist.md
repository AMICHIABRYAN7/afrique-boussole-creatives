## 📋 ÉTAPE 1: CONFORMITÉ MARQUE

### Couleurs
- [ ] **Brand Blue (#013C87)** : Utilisé EXACTEMENT pour éléments clés
  - ✓ Pas de substitution, pas de variation
  - ✓ Utiliser dans les logos, accents primaires
- [ ] **Brand Green (#1D7742)** : Utilisé pour éléments secondaires
  - ✓ Call-to-action, liens, highlights
- [ ] **Pas de couleurs substituées** : Aucune autre couleur n'a remplacé les couleurs brand
  - ✓ Vérifier tous les éléments contre palette officielle
- [ ] **Contraste WCAG AA minimum** : Tous les textes/backgrounds
  - ✓ Ratio 4.5:1 minimum pour texte petit
  - ✓ Ratio 3:1 minimum pour texte large

### Typographie
- [ ] **Font utilisée : Inter uniquement**
  - ✓ Pas de substitution, pas de mélange avec d'autres fonts
  - ✓ Tous les textes en Inter (light, regular, semibold, bold)
- [ ] **Hiérarchie typographique respectée** (voir `typography-system-pro.md`)
  - [ ] **Titre principal (H1)** : 48-72px (web) / 96-144pt (print), Bold/Black
  - [ ] **Sous-titre (H2)** : 32-40px (web) / 48-64pt (print), SemiBold
  - [ ] **Corps de texte (Body)** : 16-18px (web) / 20-24pt (print), Regular
  - [ ] **CTA** : 14-16px (web) / 18-20pt (print), SemiBold
  - [ ] **Caption** : 12px (web) / 14-16pt (print), Regular
- [ ] **Interlignage correct**
  - ✓ H1/H2 : 1.2x line height
  - ✓ Body : 1.5x line height minimum
  - ✓ CTA : 1.25x line height

### Logos
- [ ] **Logo présent** : Logo Afrique Boussole visible
- [ ] **Logo version correcte** : Full logo OU mark (jamais dégradé)
- [ ] **Clear space respecté** : Espace blanc minimum autour
- [ ] **Taille appropriée**
  - ✓ Digital : Minimum 40px (height)
  - ✓ Print : Minimum 15mm (height)
- [ ] **Arrière-plan approuvé** : Fond blanc, bleu, vert OU transparent
  - ✓ Pas d'arrière-plans "créatifs" sans approbation

## 📊 ÉTAPE 2: HIÉRARCHIE & COMPOSITION

### Clarté du Message
- [ ] **Lisible en 2 secondes** : Message principal compris sans effort
  - ✓ Utilisateur comprend l'objectif en 2 secondes
  - ✓ Aucune ambiguïté ou confusion
- [ ] **Point focal évident** : Un seul élément attire l'attention
  - ✓ Pas de concurrence entre éléments
  - ✓ Focal point au bon endroit (selon composition)
- [ ] **Hiérarchie visuelle claire**
  - ✓ Niveau 1 (primaire) = plus grand/contrasté
  - ✓ Niveau 2 (secondaire) = medium
  - ✓ Niveau 3 (support) = petit/léger

### Composition & Équilibre
- [ ] **Composition logique** : Éléments bien organisés
  - ✓ Alignement net (pas de chaos)
  - ✓ Espacement cohérent (white space intentionnel)
  - ✓ Utilise système de composition approuvé (Rule of Thirds, Center, etc.)
- [ ] **Balance visuelle** : Aucun sentiment de déséquilibre
  - ✓ Poids visuel distribué
  - ✓ Pas de "lourdeur" d'un côté
- [ ] **Contraste suffisant** : Entre éléments importants
  - ✓ Texte/background : 4.5:1 minimum
  - ✓ Éléments/fond : Visuel distinct

## 🖼️ ÉTAPE 3: IMAGES & VISUELS

### Qualité Image
- [ ] **Résolution appropriée**
  - ✓ Digital : 72-96 dpi minimum
  - ✓ Print : 300 dpi minimum
  - ✓ Pas d'image pixelisée/floue
- [ ] **Format approprié**
  - ✓ Digital : JPEG (photos), PNG (graphics)
  - ✓ Print : PDF haute-res OU TIFF 300dpi
- [ ] **Taille fichier optimisée**
  - ✓ Web : <2MB (JPEG compressé)
  - ✓ Print : <50MB (lossless)

### Authenticité Image
- [ ] **Pas de clichés stock génériques**
  - ✓ Image pertinente au message
  - ✓ Représentation authentique (pas de tokenisme)
  - ✓ Perspective africaine contemporaine
- [ ] **Qualité professionnelle**
  - ✓ Bonne luminosité/exposition
  - ✓ Bonne saturation (pas sur/sous-saturée)
  - ✓ Bonne composition de l'image elle-même
- [ ] **Cohérence visuelle**
  - ✓ Style image cohérent dans design
  - ✓ Palette couleur compatible avec brand
  - ✓ Ton/mood aligné avec message

  - ✓ Pas de CTA multiples conflictuels

- [ ] **Destination claire** : Où va l'utilisateur ?
  - ✓ Lien/formulaire fonctionne
