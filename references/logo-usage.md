# Afrique Boussole — Logo Usage Guidelines

## Overview

The Afrique Boussole logo is the primary visual identifier of the brand.

Consistent, correct usage across all materials builds recognition and reinforces brand identity.

---

## 1. LOGO VERSIONS

### Full Logo (Primary)

**Description** : Horizontal lockup with wordmark

**Use When** :

- Primary communication format
- Sufficient space available (minimum clear space observed)
- Formal, official communications
- Print materials with good resolution support

**Positioning** : Bottom right, bottom left, or center (center only for hero/title use)

---

### Logo Mark Only (Icon)

**Description** : Compass symbol or mark only (without wordmark)

**Use When** :

- Space is limited
- Favicon or small digital mark
- Corner placement with limited space
- Icon usage (app icon, etc.)

**Size** : Minimum 24px digital, 8mm print

---

### Full Logo - Monochrome White

**Description** : Logo in white color only

**Use When** :

- Dark background (Brand Blue, Brand Green, dark photography)
- Printing on colored paper or fabric
- Ensuring visibility on dark backgrounds

**Color** : #FFFFFF (pure white)

**Caution** : Ensure background is dark enough for white logo to be visible (minimum contrast 3:1)

---

### Full Logo - Monochrome Dark

**Description** : Logo in dark color only

**Use When** :

- Light background (White, Ivory, light photography)
- Printing on white paper or fabric
- Standard use on light backgrounds

**Color** : #013C87 (Brand Blue) or #0A2555 (Dark Navy)

---

### Logo - Full Color

**Description** : Standard logo with full brand colors

**Use When** :

- Digital display (web, social, screen)
- Print materials with color capability
- Professional materials

**Colors** : Brand Blue, Brand Green, neutrals as appropriate

---

## 2. LOGO SIZING

### Minimum Size

**Digital** :

- Minimum 40px height
- Smaller than this becomes illegible

**Print** :

- Minimum 15mm height (approximately 0.6 inches)
- Smaller than this loses detail

### Maximum Size

**General Rule** : Logo should not dominate the composition

- Logo typically 10-20% of total composition width
- Exceptions: Logo-focused materials (building signage, vehicle wraps)

**Do NOT** :

- Make logo larger than headline
- Make logo 50%+ of composition (except hero landing page)
- Distort sizing arbitrarily

---

## 3. CLEAR SPACE

**Definition** : Minimum unoccupied space required around logo to maintain visibility and impact

### Clear Space Calculation

**Measurement** : 1/4 of logo height

**Example** :

- If logo is 40px tall → clear space is 10px on all sides
- If logo is 100mm wide → clear space is roughly 25-30mm radius

### Visual Representation

```
┌─ Clear Space ──┐
│                │
│  ┌──────────┐  │
│  │          │  │
│  │   LOGO   │  │
│  │          │  │
│  └──────────┘  │
│                │
└────────────────┘
```

### Clear Space Violations to Avoid

- Text touching logo edge
- Images overlapping logo
- Design elements pressing on logo
- Logo crowded by content

---

## 4. ASPECT RATIO AND PROPORTIONS

### Maintain Aspect Ratio

**Rule** : Never stretch or compress logo

**Correct** :

- Scale proportionally (both dimensions increase equally)
- Use "constrain proportions" or "lock aspect ratio" in design software

**Incorrect** :

- Logo stretched horizontally (200% width, 100% height)
- Logo compressed vertically (100% width, 50% height)
- Logo skewed or distorted

**How to Check** :

- Original logo is X inches wide by Y inches tall
- Scaled version should maintain same ratio
- Example: 2:1 ratio should remain 2:1 at any size

## 5. APPROVED BACKGROUNDS

### Excellent Backgrounds

- **White (#FFFFFF)** — Primary background for logo
- **Ivory (#F7F4EC)** — Alternative light background
- **Brand Blue (#013C87)** — White or light logo required
- **Brand Green (#1D7742)** — White or light logo required
- **Photography** — If using photo background, ensure logo contrast (dark border or light halo recommended)

### Acceptable Backgrounds

- Light neutral colors (grays 80%+, light pastels)
- Solid colors with sufficient contrast
- Simple patterns (if contrast maintained)

### Prohibited Backgrounds

- Busy, complex photography (without clarity treatment)
- Brand Blue with Dark Navy logo (insufficient contrast)
- Brand Green with Brand Blue logo (insufficient contrast)
- Low-contrast colors (logo becomes invisible)
- Overly textured backgrounds (distracts from logo)

## 6. POSITIONING RULES

### Standard Positioning

**Bottom Right** (most common)

- Natural end of eye flow
- Standard placement in Western design
- Works on most composition types

```
┌─────────────────────┐
│                     │
│                     │
│  MAIN CONTENT       │
│                     │
│                 [L] │
└─────────────────────┘
```

**Top Left** (alternative)

- Professional, institutional
- Good for documents
- Natural reading start point

```
┌─[L]──────────────────┐
│                      │
│  MAIN CONTENT        │
│                      │
└──────────────────────┘
```

**Center** (only for hero use)

- Used when logo is focal point
- Landing page hero section
- Logo-focused promotion
- Avoid for standard materials

```
┌──────────────────────┐
│                      │
│      HEADLINE        │
│       [LOGO]         │
│   SUPPORTING TEXT    │
│                      │
└──────────────────────┘
```

### Positioning on Different Formats

**A4 Document** : Bottom right or bottom left

**Social Media 1:1** : Bottom right (small), or bottom center

**Website Header** : Top left or center

**Business Card** : Top left or corner

**Email Signature** : Next to sender name

**Poster** : Top left, bottom right, or bottom center (not center unless hero)

## 7. EXCLUSIONS AND PROHIBITIONS

### Never

- **Rotate** logo (except 0° or 90° only, for very specific cases)
- **Skew or distort** logo (no shearing or warping)
- **Apply effects** (no drop shadows, glows, 3D, distortions, filters)
- **Recolor** logo to non-brand colors
- **Outline or border** the logo (no white border on white logo, etc.)
- **Overlay text** on logo
- **Combine with other logos** (unless explicit co-branding approved)
- **Stretch or compress** proportions

### Prohibited Modifications

```
❌ WRONG                    ✅ RIGHT
─────────────────────────────────────
Rotated at 45°        →    Straight (0° or 90° only)
Stretched horizontally →    Proportional scaling
With drop shadow       →    Clean, no effects
Recolored to red       →    Brand colors only
Skewed/distorted       →    Perfect proportions
Multiple logos mixed   →    Single logo only
Outlined heavily       →    No outline
Text overlaid          →    Clear space around
```

## 8. BACKGROUND TREATMENT FOR CONTRAST

### When Logo Needs Help Contrasting

**Situation** : Logo on photograph or complex background

**Solution 1: Vignette/Halo**

```
Add subtle dark vignette around logo area
Dark outer edges fade to transparent
Logo sits on darkened background zone
Subtle and professional
```

**Solution 2: Solid Background Panel**

```
Place logo on white, ivory, or brand color rectangle
Rectangle is sized slightly larger than clear space
Logo sits clearly on solid background
Professional and clean
```

**Solution 3: Darkened Overlay Area**

```
Darken the area behind logo (20-30% opacity overlay)
Logo placed on darkened zone
Background remains visible but muted
Works well with photography
```

## 9. FILE FORMATS AND SPECIFICATIONS

### Digital Use (Web, Social, Screen)

**Format** : PNG with transparency (preferred)

**Resolution** : 72dpi minimum (96dpi for Retina/high-DPI screens)

**Color Space** : RGB (for web display)

**File Size** : <50KB for web use

### Print Use

**Format** : PDF or TIFF (no distortion)

**Resolution** : 300dpi minimum (600dpi for small logos)

**Color Space** : CMYK (for printing)

**File Type** : Vector (AI, EPS) preferred for scalability

## 10. LOGO USAGE CHECKLIST

Before using logo in any material:

- [ ] Logo version appropriate for context (full, mark, color, monochrome)
- [ ] Logo size meets minimum (40px digital, 15mm print)
- [ ] Aspect ratio maintained (not stretched)
- [ ] Clear space observed (1/4 height radius)
- [ ] Background has sufficient contrast
- [ ] Logo positioned appropriately for format
- [ ] Logo not rotated beyond 0° or 90°
- [ ] No effects applied (shadows, glows, distortions)
- [ ] Color is approved (Brand Blue, Brand Green, White, or Dark Navy)
- [ ] Logo clearly visible and professional-looking
- [ ] File format correct for medium (PNG for web, PDF/TIFF for print)

## 11. CO-BRANDING AND PARTNERSHIPS

### Logo Placement with Partners

**Situation** : Afrique Boussole + Partner organization

**Approach** :

1. **Equal Sizing** : Both logos similar size
2. **Separation** : Clear space between logos
3. **Balance** : Logos aligned and balanced
4. **Hierarchy** : If necessary, Afrique Boussole logo slightly larger

**Layout** :

```
Side by side:
[Afrique Boussole Logo] [Partner Logo]

Stacked (less common):
    [Afrique Boussole Logo]
    [Partner Logo]
```

**Rule** : Never blend or overlap logos

## 12. FAQ: LOGO USAGE

**Q: Can we add a tagline next to the logo?**

A: Yes, if integrated into official logo version. Do not add arbitrary text overlay.

**Q: Can we use the logo on a colored background?**

A: Yes, if contrast is sufficient. Test against background before publishing. Use white or dark logo accordingly.

**Q: Can we make the logo smaller to fit more content?**

A: No. Resize content or composition, not the logo below minimum size.

**Q: Can we add a border around the logo?**

A: No, unless it's part of the official logo design. Clear space serves the same purpose.

**Q: What if we don't have clear space?**

A: Redesign the composition to accommodate. Clear space is non-negotiable for logo integrity.

**Q: Can we rotate the logo for a dynamic effect?**

A: No, unless rotation is part of official design system (rare). Keep level and aligned.

**Q: Which version should we use for social media?**

A: Full logo (color) for most uses. Mark-only if space is severely limited.
