# Poster Workflow

## Overview

A poster is a large-format visual designed to be viewed from distance and make immediate impact.

---

## Process

1. **Receive Brief** → Objective, event/announcement, viewing distance
2. **Define Concept** → Single, powerful visual idea
3. **Identify Focal Point** → Where should eye go first?
4. **Design Hierarchy** → Large headline, supporting elements, minimal text
5. **Select Image** → High-impact photography or graphic
6. **Build Poster** → Place elements, test from distance
7. **Verify Readability** → Text readable at 1-3 meter distance
8. **Review** → Hierarchy, contrast, brand compliance
9. **Refine** → Address feedback, optimize typography
10. **Finalize** → Export at high resolution for print
11. **Deliver** → Prepare poster file and mockups

---

## Key Decisions

- **Format** : A3, A2, custom size?
- **Primary Message** : Maximum 10-15 words
- **Visual** : Photography or graphic?
- **Viewing Distance** : 1 meter? 3 meters? 5 meters?
- **Text Size** : Readable from that distance?

---

## Quality Checks

- [ ] Message readable from intended distance
- [ ] Focal point obvious
- [ ] Minimal text (not information-heavy)
- [ ] Bold, high-contrast design
- [ ] Image high-impact
- [ ] No small details (unreadable from distance)
- [ ] Brand elements visible
