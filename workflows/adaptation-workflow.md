# Format Adaptation Workflow

## Overview

Adapting a primary creative to new formats while maintaining message integrity, hierarchy, and brand identity.

---

## Process

1. **Start with Master Creative** → Approved flyer, poster, or primary version
2. **Analyze New Format** → Dimensions, platform, viewing context
3. **Identify Key Elements** → Headline, image, CTA, logo
4. **Recompose Layout** → Reorganize for new format (don't just shrink)
5. **Crop/Reframe Image** → Adjust to new aspect ratio and focal point
6. **Adjust Typography** → Resize text for readability at new size
7. **Reposition Elements** → Ensure hierarchy maintained
8. **Test Readability** → Verify text readable at intended viewing size
9. **Review Hierarchy** → Primary message still dominant?
10. **Verify Brand** → Logo, colors, identity intact?
11. **Final QA** → Format specs, file quality, final review
12. **Deliver** → Export at correct resolution

---

## Key Principles

**Hierarchy Preservation** :

- Primary message remains most prominent
- Same headline (text identical, sizing adjusted)
- Same CTA (text identical, visual adjusted)
- Supporting elements downplayed if space-constrained

**Intentional Recomposition** :

- Never just shrink or stretch
- Rethink layout for each format
- Crop image deliberately
- Reposition text for optimal flow

**Platform Optimization** :

- Consider viewing context (feed, poster distance, mobile, print)
- Safe zones respected
- Aspect ratio maintained
- Text optimized for platform

## Example: A4 to Social Formats

### Starting Point (A4 Flyer)

```
┌──────────────────────────────┐
│ IMAGE                        │ 40% height
├──────────────────────────────┤
│ HEADLINE (48pt)              │ 25% height
│                              │
├──────────────────────────────┤
│ Body text (12pt)             │ 20% height
│ Supporting info              │
├──────────────────────────────┤
│ CTA BUTTON | LOGO            │ 15% height
└──────────────────────────────┘
```

### Adaptation to 1:1 Social

**Key Changes** :

- Image cropped to square
- Headline enlarged to 56px (readable at 200px width)
- Body text removed or drastically abbreviated
- CTA moved to caption
- Logo smaller, bottom corner

```
┌──────────────────────────┐
│ IMAGE (100% height)      │
│ (centered on focal point)│
│                          │
│ HEADLINE (56px, overlaid)│ 
│                          │
│ CTA / LOGO (small)       │
└──────────────────────────┘
```

### Adaptation to 9:16 Story

**Key Changes** :

- Full vertical height used
- Image as background or full bleed
- Headline at top (large, readable)
- CTA at bottom as sticker
- Minimal additional text

```
┌──────────────────────────┐
│ HOOK / HEADLINE (top)    │
│ 56px bold                │
│                          │
│ IMAGE / VISUAL           │
│ (background or full bleed│
│                          │
│ CTA STICKER (bottom)     │
└──────────────────────────┘
```

## Checklist: Format Adaptation

- [ ] New format dimensions verified
- [ ] Aspect ratio maintains (no distortion)
- [ ] Primary message identical (text same, size adjusted)
- [ ] CTA identical (text same, styling adjusted)
- [ ] Image recomposed (not just cropped)
- [ ] Hierarchy maintained (primary still dominant)
- [ ] Text readable at intended viewing size
- [ ] Logo visible and correctly positioned
- [ ] Brand colors preserved
- [ ] Safe zones respected
- [ ] Platform specifications met
- [ ] QA passed

---

## Example Readability Testing

**1:1 Social** :
- Simulate viewing at 200px width
- Headline should be legible
- CTA should be identifiable
- Main message clear

**9:16 Story** :
- Simulate viewing on 6" mobile screen
- Headline readable
- Hierarchy obvious
- CTA accessible

**A4 Print** :
- Simulate viewing at 30cm distance
- Text minimum 10pt readable
- Image quality at 300dpi

## File Naming Convention

When delivering adapted formats, use clear naming:

```
Campaign-Name_Format_Version_Date

Example:
Webinar-Campaign_A4-Flyer_v1_2024-09-24.pdf
Webinar-Campaign_Social-1x1_v1_2024-09-24.jpg
Webinar-Campaign_Story-9x16_v1_2024-09-24.jpg
Webinar-Campaign_Web-Banner_16x9_v1_2024-09-24.jpg
```

## Adaptation Speed & Efficiency

**Fast-Track Adaptation** (when timeline tight):

1. Duplicate master file
2. Update artboard to new dimensions
3. Reposition elements
4. Adjust typography sizing
5. Crop image to new format
6. Quick QA
7. Export

**Time estimate** : 30-45 minutes per format (after first format created)

---

## When Adaptation Fails (Restart Instead)

If adaptation becomes too compromised:

- Message becomes unclear
- Hierarchy completely inverted
- Text illegible at intended size
- Core concept doesn't translate
- Looks like forced/awkward layout

**Solution** : Start fresh from brief for that format, using master as reference
