### ÉTAPE 2 — ARCHITECTURE DU FLYER (HIÉRARCHIE VISUELLE)

Définir la structure selon le framework 5 niveaux :

```
NIVEAU 1 — HOOK (Accroche visuelle)
  → Élément qui ARRÊTE le regard (image, bloc couleur, chiffre clé)
  → Occupe 30-40% de l'espace
  → Typiquement : visuel principal OU grand titre coloré

NIVEAU 2 — MESSAGE PRINCIPAL (Headline)
  → La proposition en 5-12 mots max
  → Police : Inter Black/ExtraBold, 48-72px (A4)
  → Couleur : #013C87 OU #FFFFFF selon le fond

NIVEAU 3 — VALEUR PROPOSÉE (Sous-titre + bullets)
  → "Pourquoi nous choisir" — 2-4 points forts
  → Police : Inter SemiBold, 18-24px (A4)
  → Icônes simples ou puces ✓

NIVEAU 4 — PREUVE / CRÉDIBILITÉ (Social proof)
  → Chiffres clés GAB : 98% réussite, 15+ certs, 24/7
  → Certifications / logos partenaires
  → Témoignage ultra-court si disponible

NIVEAU 5 — CTA (Appel à l'action)
  → Bouton/bandeau clairement visible
  → Texte court : "Appelez maintenant", "Inscrivez-vous", "Découvrez"
  → Suivi des contacts officiels en footer
```

### ÉTAPE 3 — CHOIX DE COMPOSITION

Sélectionner un système parmi les 7 disponibles :

| Composition | Idéal pour |
|------------|-----------|
| **Top-Down** (image en haut, texte en bas) | Flyer GAB Academy, événement avec photo |
| **Split Gauche-Droite** (visuel/texte) | Présentation service, pôle IT ou Sécurité |
| **Centered / Editorial** | Annonce importante, teaser événement |
| **Full Bleed** (image pleine page + overlay texte) | Impact maximal, flyer urgence |
| **Minimalist** (typo seule, fond blanc) | Corporate, institutionnel |
| **Z-Layout** | Flyers denses avec plusieurs infos |
| **Grid 3 colonnes** | Programme, liste de services |

### ÉTAPE 4 — PALETTE CHROMIQUE (RÉGLES STRICTES)

```
✅ COULEURS AUTORISÉES :

Dominant (60%) :
  → #013C87 (Brand Blue) — fond, gros blocs, headlines
  → #FFFFFF (Blanc) — espaces, texte sur fond bleu
  → #F7F4EC (Ivory) — fond alternatif chaud

Accent (30%) :
  → #1D7742 (Brand Green) — CTA, highlights, badges
  → #0A2555 (Dark Navy) — textes subtils, borders

Support (10%) :
  → #2BA696 (Light Teal) — accents légers
  → #D4B896 (Warm Beige) — texture, motifs africains

🚫 INTERDITS ABSOLUS :
  → Toute autre couleur dominante non listée ci-dessus
  → Dégradés non approuvés
  → Couleurs vives aléatoires (rouge, orange, rose, jaune)
```

### ÉTAPE 5 — TYPOGRAPHIE (RÈGLES STRICTES)

```
Police UNIQUE : Inter (toutes déclinaisons)
Jamais de mélange avec d'autres polices.

HIÉRARCHIE FLYER A4 :
  H1 Headline   → Inter Black,    48-72px  (print: 96-144pt)
  H2 Sous-titre → Inter Bold,     28-36px  (print: 56-72pt)
  H3 Sections   → Inter SemiBold, 22-26px  (print: 44-52pt)
  Body           → Inter Regular,  16-18px  (print: 20-24pt)
  CTA Bouton     → Inter Bold,     16-20px  (print: 22-26pt)
  Caption/Footer → Inter Regular,  12-14px  (print: 14-16pt)

HIÉRARCHIE FLYER A5 (réduire de ~20%) :
  H1 → 38-56px  |  Body → 13-15px  |  Footer → 10-12px

HIÉRARCHIE DIGITAL (Instagram/WhatsApp) :
  H1 → 64-96px  |  Body → 28-36px  |  CTA → 32-40px

RÈGLES TYPOGRAPHIQUES :
  ✓ Interlignage H1/H2 : 1.1-1.2x
  ✓ Interlignage Body  : 1.5-1.6x
  ✓ Letter-spacing titres : -0.02em à -0.04em (plus compact, plus fort)
  ✓ Letter-spacing body   : 0 à 0.01em
  ✓ Majuscules : Uniquement pour labels courts (badges, tags, CTA court)
  ✓ Texte max sur fond bleu : BLANC uniquement
  ✓ Texte max sur fond blanc/ivory : #013C87 OU #0A2555
```
