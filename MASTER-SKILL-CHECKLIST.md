**Structure exacte à utiliser TOUJOURS**:

```
┌─────────────────────────────────────────────────┐
│  [Carte Afrique]  [Compass] AFRIQUE (vert)     │
│  [réseau blanc]   [G vert]   BOUSSOLE (bleu)   │
│                              ―― GROUPE ――     │

```

**Spécifications**:
- LEFT (35%): Carte Afrique bleue #013C87 + réseau blanc

- RIGHT (50%): AFRIQUE (vert) / BOUSSOLE (bleu) / GROUPE (bleu)

**À vérifier**:
- [ ] Logo présent et complet (3 parties)
- [ ] Carte Afrique visible avec réseau blanc
- [ ] Compass vert avec "G" blanc visible

- [ ] Proportions: 35% / 15% / 50%

### ✅ PLACEMENT LOGO

**Règles strictes**:

- **Position**: Top-left OU top-center
- **Taille**: 15% (minimum 5%, maximum 25%)
- **Visibilité**: Toujours visible et lisible
- **Aspect ratio**: Preserved
- **Chevauchement**: Compass peut chevaucher légèrement la carte

**À vérifier**:
- [ ] Logo top-left ou top-center (pas bottom)
- [ ] Logo ~15% de la fiche
- [ ] Logo pas trop petit (minimum visible)
- [ ] Logo pas trop grand (maximum 25%)

---

### ✅ TEXTE & CONTRASTE

**Règles de lisibilité**:

- **Texte blanc**: UNIQUEMENT sur fond bleu #013C87
- **Contraste minimum**: 4.5:1 (WCAG AA)
- **Hiérarchie**: Titre > Sous-titre > Contenu > CTA
- **CTA buttons**: Fond vert #1D7742, texte blanc #FFFFFF

**À vérifier**:
- [ ] Texte blanc UNIQUEMENT sur bleu
- [ ] Contraste suffisant pour lire
- [ ] Hiérarchie claire (titre le plus gros)
- [ ] CTA button = vert avec blanc

### ✅ TYPES DE FICHES

**5 formats disponibles**:

#### 1. FLYER FORMATION (A4)
- Dimensions: 1080×1440px
- Header bleu (30%) + Contenu blanc (50%) + Footer ivoire (20%)
- Logo top-left, titre blanc dans header
- Modules, dates, lieu dans contenu
- CTA vert dans footer

#### 2. SOCIAL MEDIA (1:1 Carré)
- Dimensions: 1080×1080px
- Fond bleu ou vert
- Titre blanc gros au centre
- Logo emblem bottom-right
- CTA bouton ou "Swipe up"

#### 3. EVENT POSTER (Vertical)
- Dimensions: 720×1080px
- Hero vert (35%) + Détails blanc (50%) + CTA bleu (15%)
- Logo top-center
- Dates/heures/lieu bien visibles
- CTA button en bas

#### 4. BRAND GUIDELINE CARD (Landscape)
- Dimensions: 1200×800px
- Panneau gauche: Logo + company name
- Panneau droit: Palette couleurs + valeurs brand
- Minimaliste et clean

#### 5. WEBSITE BANNER (Wide)
- Dimensions: 1920×400px
- Left: Texte blanc sur bleu
- Right: Visuel/symbole sur vert
- Logo top-left
- CTA button blanc avec texte vert
