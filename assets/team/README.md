## 📸 Spécifications techniques

- **Format** : JPEG haute qualité
- **Dimensions** : ~1200x1200px (carré)
- **Résolution** : 72 DPI (web) / 300 DPI (print)
- **Fond** : Neutre professionnel

## ✅ Checklist ajout nouveau membre

1. Photo portrait professionnel (fond neutre)
2. Dimensions : 1200x1200px minimum
3. Naming : `team_{role}_{timestamp}-{id}.jpg`
4. Compression : 85% qualité JPEG
5. Ajout dans `ASSETS-INVENTORY.md`

---

## 🔄 Mise à jour

Pour remplacer une photo :
1. Garder le même nom de fichier
2. Vérifier cohérence visuelle avec autres portraits
3. Notifier l'équipe marketing
