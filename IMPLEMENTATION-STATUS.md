6. **Credibility/Proof** - Why believe?
7. **Format/Distribution** - Where/how?

## 📐 TECHNICAL SPECIFICATIONS

### **Questionnaire System**

```
User types /command
    ↓
Agent ÉTAPE 0: Load all assets
    ↓
Agent: "Assets loaded, ready"
    ↓
Agent: Question 1 with multiple choice
User: Selects answer
    ↓
[Repeat for Q2-Q7/Q8]
    ↓
Agent: Show brief summary
User: Confirm (Yes/No)
    ↓
[If Yes] → Generation begins
[If No] → Revise questions
    ↓
Agent: Generate visuals using:
  - Asset palette
  - Typography hierarchy
  - Composition patterns
  - CTA best practices
    ↓
Agent: Run validation checklist (50+ items)
    ↓
Agent: Deliver files with report
```

### **Asset Loading (ÉTAPE 0)**

```
Invisible to user, but mandatory:

1. Parse asset-integration-mandatory.md
   ├─ Extract palette: #013C87, #1D7742, whites, blacks
   ├─ Extract hierarchy: H1 72px Bold → H2 32px → Body 18px
   ├─ Extract CTA patterns: Position, size, style
   └─ Extract composition: Focal point, balance, alignment

2. Load typography-system-pro.md
   ├─ Inter font only
   ├─ Web sizes: H1 48-72px, H2 32-40px, Body 16-18px, CTA 14-16px
   ├─ Print sizes: H1 96-144pt, H2 48-64pt, Body 20-24pt, CTA 18-20pt
   └─ Accessibility: 1.2x-1.5x line height, 4.5:1 contrast min

3. Load relevant reference designs
   ├─ For /flyer → load 4 flyer designs
   ├─ For /affiche → load 6 poster designs
   ├─ For /social → load 4 social designs
   └─ For /comm → load templates + social designs

4. Announce: "✅ Assets loaded (palette extracted, typography confirmed)"
```

### **Validation Checklist (50+ checks)**

```
Before delivery, verify:

✓ Colors: Exact brand colors used
✓ Typography: Inter font, correct sizes/weights
✓ Logo: Correct version, proper sizing
✓ Hierarchy: Visual priority clear
✓ Message: Readable in 2 seconds
✓ Focal point: Single, obvious
✓ Composition: Aligned, balanced, intentional
✓ Image quality: High-res, professional
✓ Typos: Zero errors
✓ CTA: Specific, visible, actionable
✓ Format: Correct dimensions
✓ Accessibility: WCAG AA 4.5:1 contrast
✓ Assets: All mandatory assets used
✓ Anti-patterns: Zero critical fails
✓ Approval: Checklist 100% passed

IF ALL GREEN → READY TO DELIVER
```
