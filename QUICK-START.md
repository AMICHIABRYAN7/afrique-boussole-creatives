# 🚀 GUIDE DE DÉMARRAGE RAPIDE - AFRIQUE BOUSSOLE CREATIVES SKILL

**Pour les utilisateurs de Kiro AI**

---

## 🎯 **COMMENT UTILISER CE SKILL ?**

### **MÉTHODE 1 : COMMANDES SLASH** (Recommandé)

Tapez simplement l'une de ces commandes dans Kiro :

```
/campagne    → Créer une campagne marketing complète
/flyer       → Créer un flyer professionnel
/affiche     → Créer une affiche événementielle
/comm        → Créer du contenu de communication
```

**Ce qui se passe ensuite :**
1. ✅ Kiro te pose 7-8 questions ciblées
2. ✅ Tu réponds naturellement
3. ✅ Kiro génère un brief structuré
4. ✅ Kiro propose 2-3 angles créatifs
5. ✅ Kiro créé le/les visuel(s)

**Durée totale** : 5-10 minutes ⏱️

---

### **MÉTHODE 2 : DEMANDE NATURELLE**

Dis simplement ce dont tu as besoin :

```
"Je veux créer un flyer pour notre événement du 15 octobre"
"Aide-moi à concevoir une campagne Instagram"
"J'ai besoin d'une affiche pour recruter des participants"
```

Kiro comprendra et te guidera ! 🤖

```

a) 🎉 Événement (conférence, workshop, webinaire)

c) 🛍️ Produit / Service commercial
```

**TOI** : `a) Événement`

```
❓ Si quelqu'un voit votre flyer 2 secondes, il doit comprendre :

QUOI : Quel est l'événement ?
OÙ : Lieu (si physique) ou plateforme
QUAND : Date et heure
```

**TOI** :
```
QUOI : Workshop IA pour entrepreneurs
OÙ : Impact Hub Dakar
QUAND : 15/10/2026 à 14h
```

... *et ainsi de suite*

**RÉSULTAT** : Flyer professionnel prêt en 5 minutes ! ✅

## 🎨 **CE QUE KIRO FAIT AUTOMATIQUEMENT**

### **Sans que tu le demandes :**

✅ **Applique la charte graphique** Afrique Boussole
   - Couleurs : #013C87 (Bleu), #1D7742 (Vert)
   - Police : Inter
   - Logo placé correctement

✅ **Optimise la hiérarchie visuelle**
   - Headline = 40% de l'attention
   - CTA clair et visible
   - Espaces blancs équilibrés

✅ **Respecte les standards**
   - Accessibilité WCAG AA
   - Résolution appropriée (web 72 DPI, print 300 DPI)
   - Formats d'export corrects

✅ **Adapte au canal**
   - Instagram → 1080x1080px ou 1080x1920px
   - LinkedIn → 1200x628px
   - Print → A4/A3 300 DPI

## ❓ **QUESTIONS FRÉQUENTES**

### **Q : Combien de temps ça prend ?**
**R** : 5-10 minutes pour un visuel simple, 20-30 minutes pour une campagne complète.

### **Q : Puis-je modifier le résultat ?**
**R** : Oui ! Demande des ajustements :
- "Change la couleur en vert"
- "Agrandis le titre"
- "Ajoute un QR code"
- "Créé une version anglaise"

### **Q : Kiro peut créer les images aussi ?**
**R** : Oui, Kiro utilise DALL-E ou recommande des stocks photos appropriées.

### **Q : Ça fonctionne en français et anglais ?**
**R** : Oui, tu peux demander des créations dans les deux langues.

### **Q : Que faire si je n'ai pas toutes les réponses ?**
**R** : Pas grave ! Kiro peut :
- Te guider avec des exemples
- Proposer des defaults intelligents
- T'aider à clarifier ton message

## 🎯 **BONNES PRATIQUES**

### **✅ À FAIRE**
- Réponds honnêtement aux questions (pas de "joli design", mais "quel résultat ?")
- Fournis des détails concrets (dates, lieux, chiffres)
- Teste 2-3 angles créatifs proposés
- Demande des révisions si besoin

### **❌ À ÉVITER**
- Vouloir tout dire dans un seul visuel
- Négliger le public cible
- Oublier le call-to-action
- Ignorer les suggestions de Kiro
